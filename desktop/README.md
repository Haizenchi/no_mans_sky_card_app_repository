# Desktop source

This folder contains the Tauri 2 desktop wrapper for NMS Passport.

- `src/` — desktop snapshot of the NMS Passport v2.2 frontend.
- `src-tauri/` — native Tauri/Rust wrapper and minimal capabilities.
- `package.json` — local Tauri CLI commands.

Build on Windows with:

```bash
npm install
npm run desktop:build
```
